## Status legend

- ✅ Active — currently running or in visibility window
- 🕓 Upcoming — scheduled, outside visibility window
- 📦 Completed — finished, in archive
- ♻️ Recurring — permanent league/competition, no end date
- 📝 Planned — not yet integrated, candidate for future addition

## Verification legend

- 🟢 Dates and host officially confirmed by governing body
- 🟡 Reported but not officially confirmed
- 🔴 TBC / unknown / pending announcement

## Atlas Kings priority signal

- **P1 — Headline featured**: Morocco hosts/co-hosts
- **P2**: Atlas Lions senior men's
- **P3**: Atlas Lionesses senior women's
- **P4**: Morocco youth (U-17, U-20, U-23 men/women)
- **P5**: Moroccan club in continental
- **P6**: Moroccan player in major foreign tournament
- **P7**: Arab audience interest (no direct Morocco signal)
- **P8**: Global headline (no Morocco signal)

# Implementation notes for engineers

This document drives the following code:

1. **`src/lib/constants/competitions.ts`** — `VERIFIED_COMPETITIONS` array. Each entry here corresponds to a competition above with `🟢` verification (or `🟡` with caveat). Status maps to tier + slug + IDs.

2. **`src/lib/competitions/visibility.ts`** (Phase 4.5 to build) — `getVisibleCompetitions(today: Date)` function reads this calendar's dates and `morocco_relevance` signals to compute today's featured topbar slots.

3. **`src/lib/competitions/featured-slots.ts`** (Phase 4.5 to build) — Priority resolution for the 2 featured topbar slots. Reads `tournament_start_date`, `tournament_end_date`, `visibility_window_days`, and `morocco_relevance` from competition metadata.

4. **EditionSelector component** (Phase 6+) — Reads this calendar's "Completed" entries to populate year-switching dropdown on competition pages.

5. **WC 2026 countdown banner / WC 2030 countdown banner** — Reads dates from this file to show countdown only when in visibility window.

When a tournament concludes, update its `Status` to `📦 Completed` and add result notes. When dates change, update the entry and append to Update Log.

When adding a new competition, place it in the correct Tier section, fill all metadata fields, and add an entry to Update Log explaining the addition.
